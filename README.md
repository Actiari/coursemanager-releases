# CourseManager downloads

[Download the latest Windows installer](https://github.com/Actiari/coursemanager-releases/releases/latest)

This repository distributes CourseManager installers and their matching `.sha256` checksums. Application source and build history are private and are not stored here.

Download `CourseManager-X.Y.Z-setup.exe` from a release's Assets section. Later updates are available in the app under Settings → Updates.

GitHub's automatically generated source archives contain only this download documentation, not the application source.
